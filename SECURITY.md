# Security Policy

## Supported Versions

Security fixes are considered for the default branch. This project does not currently maintain separate release branches.

## Reporting a Vulnerability

Please report security concerns privately instead of opening a public issue. Use GitHub's private vulnerability reporting if it is available for this repository, or contact the maintainer through their GitHub profile.

Include as much detail as you can safely share:

- A description of the vulnerability.
- Steps to reproduce it.
- Affected files, commands, or inputs.
- Any known impact.
- Suggested fixes, if you have them.

## Scope

Relevant security reports include issues such as unsafe file handling, dependency vulnerabilities, malformed ROM inputs causing unexpected host behavior, or tooling workflows that could expose local data.

Please do not include copyrighted ROMs in reports. If a ROM is needed to reproduce a problem, use a minimal synthetic ROM or describe how to construct one.

## Expectations

The maintainer will review reports as time allows and may ask for more information. Public disclosure should wait until a fix or mitigation is available.
