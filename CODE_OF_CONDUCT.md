# Code of Conduct

This project should be a focused, respectful place to work on emulator code.

## Expected Behavior

- Be considerate and constructive in issues, pull requests, and reviews.
- Assume good intent while still asking for evidence when accuracy matters.
- Keep feedback specific to the code, documentation, tests, or project goals.
- Be patient with contributors who are learning PHP, emulation, or open source workflows.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Personal attacks or repeated hostile comments.
- Publishing private information without permission.
- Derailing technical discussions after a maintainer asks to move on.

## Reporting

If you see behavior that makes the project less welcoming or safe, contact the maintainer privately when possible. Maintainers may remove comments, close threads, block users, or take other reasonable action to protect the project.

## Scope

This code of conduct applies to project spaces, including GitHub issues, pull requests, discussions, and any other official project communication channels.
